That is the frozen application built on 2026-09-05 at 01:19:48 EDT for the original seven-Blob benchmark. Its matching portable PDB has SHA-256 `04b6369bf2fc5137dd51039ef40423a5fb28f2a79722a5a386825dc2dfb0f893` and names `AllBlobBenchmark.gs`.

The original task source manifest records `AllBlobBenchmark.gs` as 26,628 bytes with SHA-256 `49df8b608a42a8750a6a792bc829a22e29bec1125318900ce74139e2bda552a0`. Reconstructing the added file from `/tmp/goo-all-blobs/task.patch` produces byte-identical `/tmp/goo-post-checkpoint/reconcile-benchmark/provenance-allblob-driver.gs.txt`. The archived `docs/perf/evidence/all-blobs-2026-09-05/SHA256SUMS` authenticates `frozen-binaries.json`, `source-hashes.json`, and `task.patch`. Its manifest records that the source and patch hashes match.

The current checkout's `AllBlobBenchmark.gs` has SHA-256 `84a90bc325c446612eab25bf3a5ab8d49d1bf4b25018298d9e38c3dffa3336d3`. The exact diff is saved as `/tmp/goo-post-checkpoint/reconcile-benchmark/provenance-allblob-current.diff`. Current source adds two untimed cold observations, `/proc/self/smaps_rollup` reporting, allocation P95 reporting, and an ordinal offset of two. It does not change the Blob workload classes, full-mutation branch, measured `ForceRender` and `DrainWindowQueue` timing scope, frame validation, timestamp validation, slot validation, or cleanup. In Container/full mode, `AllBlobRoot.Advance` ignores its frame argument and toggles all 1,000 leaves. The old and current sources therefore perform the same measured workload operations, but the complete driver IL is not byte-identical.

The old driver predates the current ShaderEffect replacement marker and retained-data warmup diagnostic. It cannot qualify the current ShaderEffect route. This does not create a lane bias in its AllBlob comparison because `GOO_ALL_BLOB_BENCHMARK=1` dispatches directly to `RunAllBlobBenchmark`, both lanes used the same `08f1c670...` application, and only `Goo.dll` changed. The first private comparison remains authenticated historical evidence but is superseded for the final performance claim by the current-driver rerun.

The measured benchmark fixture is preserved byte-for-byte as a `.gs.txt` evidence source because it fails current GL0001 formatting. Formatting it after measurement would break source provenance.
