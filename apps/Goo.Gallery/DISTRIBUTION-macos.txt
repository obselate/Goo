GOO GALLERY FOR MACOS

Requirements

- Apple Silicon Mac
- macOS 15 or newer
- No administrator password

Install and launch

curl -fsSL https://github.com/obselate/goo/releases/latest/download/install-goo-gallery-macos.sh | bash

The installer downloads the current Goo Gallery app bundle, verifies its SHA-256 checksum, installs it under ~/Applications, removes quarantine only from that app, and launches it. An existing copy is moved to Trash before replacement.

The app is unsigned beyond ad-hoc code signing. The installer command is the explicit trust step and avoids the normal Gatekeeper dialog without changing system security settings.
